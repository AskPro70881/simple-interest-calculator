# Simple Interest Calculator

A simple calculator that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

## Inputs

- Principal amount
- Rate of interest
- Time period

## Output

The calculator displays the calculated simple interest.

## Example

If:

- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100

## Project Purpose

This project demonstrates the basic calculation of simple interest and the use of GitHub for project documentation.
